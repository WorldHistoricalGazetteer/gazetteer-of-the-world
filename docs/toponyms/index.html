Gazetteer of the World — place-name identification

The 1856 Gazetteer of the World spells place names by conventions long superseded, and automatic matching gets them badly wrong. For most entries the book also printed coordinates, so below each name are the places our gazetteer actually holds near that point. Usually you only need to pick one. Nothing is uploaded; your work stays in this browser until you export it.

How to use this. Pick the matching place, or type the modern name if none fit, or press Not identifiable and move on. Work is saved in this browser automatically, so you can close the page and come back. When you have done as much as you want, press Export and email the downloaded file to stephen@docuracy.co.uk. Partial work is genuinely useful — please do not feel you need to finish. If you are unsure, mark it unsure rather than guessing: an uncertain answer marked uncertain is useful to us, a confident-looking guess is not.
